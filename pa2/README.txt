CAPP 30121: Schelling Model of Housing Segregation
--------------------------------------------------

These are the files for Programming Assignment #2.

- schelling_student.py: skeleton code. Your code goes in this file.
  This file is the only file that you will modify.

Do NOT modify the following files.

- pyproject.toml: a configuration file for use with uv. Before
  you start working on this assignment run:

    $ uv sync

  to load the necessary libraries.

- schelling.py: command-line interface for the program

- utility.py: utility functions used to test the code plus one
  utility function---sort_locations_by_differential---to be used
  in the solution.

- test_do_simulation.py: automated tests for the required do_simulation
  function.

- sample_cities/: A directory contains files with example cities

- tests/: A directory containing files specifying the tests

- README.txt: the README file
