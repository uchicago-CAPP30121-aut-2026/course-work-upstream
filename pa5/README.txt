CAPP 30121: Visualizing Time Use Data Using TreeMaps
----------------------------------------------------

These are the files for Programming Assignment #5.

- treemap.py: skeleton code.  You will do your work in this file

Do NOT modify the following files.

- data.zip: the data for this assignment.  To decompress this data,
  run: unzip data.zip.

- atus.py -  a program for generating treemaps from ATUS data

- fdic - a program for generating a treemap from FDIC data

- rect.py - a simple class for representing rectangles

- drawing.py - a simple drawing library

- tests/ - A directory containing files specifying the tests

- test_treemap.py - the automated tests for this assignment

- pyproject.toml: a configuration file for use with uv. Before
  you start working on this assignment run:

    $ uv sync

  to load the necessary libraries.

- helpers.py: some helper functions used by the test code.

- tests/ A directory containing files specifying the tests

- README.txt: the README file
