CAPP 30121: Ranked Choice Voting
--------------------------------------------------

These are the files for Programming Assignment #3.

- ranked_choice_student.py: skeleton code. Your code goes in this file.

- student_tests.py: your test code goes in this file.

Do NOT modify the following files.

- pyproject.toml: a configuration file for use with uv. Before
  you start working on this assignment run:

    $ uv sync

  to load the necessary libraries.

- uv.lock: a file that tells uv exactly which version of the libraries
  we used.

- ranked_choice.py: command-line interface for the program

- ballot_files/: a directory with sample ballots

- tests/ A directory containing files specifying the tests

- README.txt: the README file
