CAPP 30121: Modeling Epidemics
------------------------------

These are the files for Programming Assignment #1.

- sir_student.py: skeleton code. Your code goes in this file.
  This file is the only file that you will modify.

Do NOT modify the following files.

- pyproject.toml: a configuration file for use with uv. Before
  you start working on this assignment run:

    $ uv sync

  to load the necessary libraries.

- sir.py: command-line interface for the program

- test_sir_student.py: test code for use with pytest.  See
  the assignment writeup for information about how to
  run these tests.
  
- helpers.py: code for reading cities from file and other helper
  functions.  This code is used by the test code and by the CLI.

- tests/: A directory containing files specifying the tests.

- sample_cities: A directory contains files with example cities.

- README.txt: the README file
